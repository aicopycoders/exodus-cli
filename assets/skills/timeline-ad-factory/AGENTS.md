# Agent instructions (Codex)

When the user asks for a timeline ad, a Day 1 / Week 2 / Month 3 ad, a skeleton or Pixar timeline ad, or to turn a winning ad (brief, sales page link, or transcript) into timeline ads:

1. Read `timeline-ad-factory/SKILL.md` in full and follow it exactly, stage by stage.
2. Read each `timeline-ad-factory/reference/*.md` file at the stage where SKILL.md tells you to.
3. Run the Python scripts from the project's top folder, e.g. `python timeline-ad-factory/scripts/gen_vo.py projects/<name>`.
4. Stop at every gate marked STOP and wait for the user's explicit approval before spending money.
